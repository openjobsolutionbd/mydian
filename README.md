# মি — Mydian

একটা ব্যক্তিগত, স্ব-হোস্টেড মার্কডাউন নোট অ্যাপ। ব্রাউজারে চলে, দেখতে ও
ব্যবহার করতে অনেকটা Obsidian-এর মতো, কিন্তু হালকা এবং দ্রুত — শুধু
মার্কডাউন লেখা ও গুছিয়ে রাখার জন্য।

🔗 **লাইভ অ্যাপ:** https://mydian-tei.pages.dev

---

## এই অ্যাপ কী করে

- **মার্কডাউন নোট লেখা** — লাইভ-প্রিভিউ এডিটর (হেডিং, বোল্ড, লিংক ইত্যাদি
  টাইপ করার সাথে সাথেই সঠিকভাবে দেখায়, ঠিক Obsidian/Notion-এর মতো)
- **ফোল্ডার দিয়ে গুছিয়ে রাখা** — নোটকে ফোল্ডারে ভাগ করে সাজানো যায়
- **দ্রুত লোড হয়** — একবার খোলার পর ফাইল-তালিকা ও নোট লোকালি ক্যাশ থাকে,
  পরের বার সাথে সাথে খোলে (ইন্টারনেট ধীর হলেও)
- **নাম পরিবর্তন, ডিলিট, অ্যাটাচমেন্ট আপলোড** (ছবি/PDF)
- **PWA** — ফোনে বা কম্পিউটারে অ্যাপের মতো ইনস্টল করা যায়
- **PIN দিয়ে সুরক্ষিত** — শুধু আপনি ঢুকতে পারবেন

## ডেটা কোথায় থাকে

নোটগুলো এই রিপোতে থাকে না — আলাদা একটা প্রাইভেট রিপোতে
(`mydian-vault`) থাকে, GitHub-এ। এই রিপোতে (`mydian`) শুধু অ্যাপের
কোড আছে। এর মানে:

- প্রতিটা নোটের সম্পূর্ণ পরিবর্তনের ইতিহাস (version history) চিরকাল
  সংরক্ষিত থাকে, বিনামূল্যে
- আপনার নোট আর অ্যাপের কোড কখনো মিশে যায় না

## টেক স্ট্যাক (কারিগরি বিবরণ)

Vanilla JavaScript (কোনো framework নেই), Cloudflare Pages-এ হোস্ট,
GitHub API-র সাথে যোগাযোগের জন্য একটা ছোট Cloudflare Worker প্রক্সি
(যাতে GitHub token ব্রাউজারে কখনো প্রকাশ না হয়)।
